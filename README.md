# 하루 시계 (Haru Clock)

스마트폰·태블릿용 오프라인 지원 웹 시계입니다. 최신 Sites 배포 버전 17의 소스와 테스트를 보관합니다.

- 운영 주소: https://seoul-tablet-clock.grebarohere.chatgpt.site/
- 가져온 원본 커밋: `1ebde0176abf10c2eb1e6e0ee84f0b5214154c3d`
- 가져온 날짜: 2026-10-17

## 기능

큰 시계·듀얼 시계·사진 시계, 디지털·아날로그, 숫자 스타일 11종, 6개 언어, 색상 설정, 주야간 밝기, 번인 완화 이동, 사진 삭제·셔플·전환 효과, 날씨와 섭씨·화씨 표시를 제공합니다.

## 폴더

- `dist/`: 배포할 정적 웹 파일과 글꼴
- `tests/`: 계산·화면 동작·사진 기능 테스트
- `.openai/hosting.json`: 기존 Sites 배포 식별 및 설정

## 로컬 실행

Python 3이 설치되어 있다면 프로젝트 폴더에서 실행합니다.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. `index.html`을 파일로 직접 열면 일부 웹 기능이 작동하지 않습니다.

## 테스트

Node.js 24 환경에서 다음 검사를 수행했습니다.

```sh
node tests/core.mjs
node tests/ui.mjs
node tests/photos.mjs
```

테스트는 계산과 모의 Canvas/DOM 동작을 검증합니다. 실제 스마트폰 브라우저의 표시·설치·오프라인 동작을 검증한 것은 아닙니다.

## 설치와 데이터

HTTPS 배포 주소를 Chrome에서 열고 오프라인 준비 완료를 확인한 뒤 홈 화면에 추가합니다. 처음 저장할 때는 인터넷이 필요하며, 최신 날씨 갱신에도 인터넷이 필요합니다.

개인 사진은 기기 브라우저의 IndexedDB에, 설정은 localStorage에 저장되므로 이 저장소에는 포함되지 않습니다. 사이트 데이터를 지우면 해당 데이터도 사라집니다.

## 배포와 업데이트

이 저장소는 현재 코드 보관용입니다. GitHub에 코드를 수정하는 것만으로 기존 Sites 사이트가 자동 배포되지는 않습니다. 배포할 때는 `dist/`를 정적 디렉터리로 사용하세요. 코드 파일의 버전을 바꾸면 `index.html`, `sw.js`의 캐시 이름 및 파일 목록도 함께 갱신해야 합니다.

기존 Sites 사이트의 배포 설정은 보존했습니다. 다른 프로젝트로 배포할 때는 해당 프로젝트에 맞게 설정해야 합니다.

## 글꼴

동봉 글꼴은 각 `dist/fonts/*-OFL.txt`에 있는 SIL Open Font License 조건을 따릅니다. 프로젝트 자체의 별도 공개 소프트웨어 라이선스는 지정하지 않았습니다.
